# Замер скорости скачивания

Консольный скрипт скачивает один адрес 10 раз подряд, каждый раз дожидается полного ответа и печатает среднее время, общий объём и скорость.

Нужен Python 3.10 или новее. Сторонние пакеты не нужны.

## Запуск

```bash
python3 speed.py "https://speed.cloudflare.com/__down?bytes=10000000"
